Megastructures

Scale through composition, not giant cubes.

Door -> Room -> Building -> District -> Megastructure

Large primitives: support columns, bridge spans, bulkheads, utility shafts, trusses, cable towers, pipe networks, foundation blocks.

Design Philosophy

  • Gameplay metrics come first.
  • World scale is always metric.
  • Modules are reusable forever.
  • Build upward through composition.
  • Collision serves gameplay, not visuals.
  • Keep one Blender -> Godot pipeline.
  • Think in systems, not one-off assets.
