## Monitoring

Synthetic monitoring is the use of bots to navigate specific checkpoints and addresses within your web app to simulate a normal user experience. Using logging and monitoring tools, you can see identify issues across your domain.

Logging is big. Know language logging features, libraries for storing, parsing, and evaluating logs. Create a policy for logging storage, backups, and retention.
